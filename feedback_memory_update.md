name: Ask before context compression
description: Must ask user whether to update memory files before context compression happens
type: feedback
---

Before context compression, always ask user if they want to update memory files.

**Why:** User wants to ensure important decisions and fixes are captured before conversation context is lost.

**How to apply:** When approaching context limits, proactively ask "需要更新 memory 文件吗？" before compression occurs.
